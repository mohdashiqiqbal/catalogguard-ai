# CatalogGuard AI

**Agentic AI for Product Catalogue Quality Assurance**

## Overview
CatalogGuard AI is an Agentic AI project that identifies product catalogue quality issues, investigates discrepancies using trusted reference records, proposes corrections for human approval, and verifies approved changes.

## Problem Statement
Inconsistent product descriptions, incorrect specifications, category mismatches, and duplicate listings can confuse customers and reduce e-commerce search quality.

## Objectives
- Detect missing and inconsistent product information.
- Identify exact and potential duplicate listings.
- Compare product entries with trusted reference records.
- Generate evidence-backed correction proposals.
- Require human approval before applying changes.
- Verify approved corrections and generate a quality report.

## Technology Stack
- Python
- Pandas and NumPy
- Streamlit
- RapidFuzz
- LLM integration for agentic investigation
- Git and GitHub
